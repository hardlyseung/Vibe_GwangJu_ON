좌표 채우기 도구

문화관광해설 거점의 도로명주소를 위도·경도로 바꿉니다. 카카오맵 JavaScript 키만 사용하므로 별도의 REST API 키나 프로그램 설치가 필요 없습니다.

사용법

  1. 아래 좌표 채우기 버튼을 누릅니다.
  2. 표에서 확인 필요 또는 실패 항목이 있는지 봅니다.
  3. 결과 전체 복사를 누릅니다.
  4. GitHub에서 data/places.json 을 열어 연필 아이콘을 누르고, 전체 선택 후 붙여넣고 Commit 합니다.

원본 데이터가 갱신되면 이 페이지를 다시 열어 같은 과정을 반복하면 됩니다.
