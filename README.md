# 광주 ON AIR

광주관광공사 개방데이터로 만든 **문화관광해설 거점 안내 서비스**.
지도에서 거점을 찾고, 공식 자료에 근거한 AI 해설을 듣고, 자료로 답할 수 없을 때는 현장 해설사로 연결됩니다.

**배포 주소**: https://vibe-gwang-ju-on.vercel.app/

2026 광주관광공사 노코드·바이브코딩 AI 활용 데이터 공모전 출품작입니다.

---

## 무엇을 하는가

| 기능 | 설명 |
|---|---|
| **AI 추천** | "아이랑 반나절", "5·18 발자취" 처럼 말하면 AI가 조건을 해석해 거점을 골라 줍니다. 목록·지도가 함께 좁혀집니다. |
| **거점 찾기** | 테마 4종 · 이름/주소 검색 · 내 위치에서 가까운 순 정렬 |
| **지도** | 테마별 색상 마커. 누르면 요약·길찾기가 담긴 카드가 뜹니다. |
| **AI 문화관광해설** | 해설 톤 3종 × 언어 4종. `places.json` 에 있는 내용만을 근거로 답합니다. |
| **빠른 안내** | AI 없이 데이터만으로 즉답. AI가 멈춰도 이 영역은 동작합니다. |
| **활용한 공공데이터** | 어떤 데이터를 무엇에 썼는지, 검증 과정에서 무엇을 정정했는지 공개합니다. |

## 설계 원칙

**하나가 죽어도 서비스는 산다.** 외부 의존성은 각각 독립적으로 실패할 수 있고, 실패해도 나머지는 동작합니다.

| 실패 | 대응 |
|---|---|
| 카카오 SDK 로드 실패 | 지도 자리에 원인 안내. 목록·상세·AI는 정상 |
| AI 실패·한도 초과·안전필터 차단 | 규칙 기반 빠른 안내는 정상 |
| AI 추천 실패 | 규칙 기반 낱말 검색으로 자동 전환 |
| 전시·행사 데이터 미변환 | 해당 섹션만 자동 숨김 |
| 좌표 없는 거점 | 목록에 표시, 길찾기는 주소 검색으로 대체 |

**모르는 것을 지어내지 않는다.** 미작성 필드는 `TODO` 로 남기고, `isFilled()` 가 화면 표시와 AI 프롬프트 양쪽에서 걸러냅니다. AI가 돌려준 거점 id 도 `places.json` 과 대조해 없는 id는 서버에서 잘라냅니다.

**정직하게 표시한다.** 건수는 실제 배열에서 셉니다. 레코드가 0인 데이터셋은 "활용했다"고 적지 않고 카드 자체를 표시하지 않습니다.

## 구조

빌드 도구·프레임워크가 없습니다. 순수 HTML/CSS/JS + 서버리스 함수 1개입니다.

```
index.html                      화면 구조
css/style.css                   디자인 토큰 · 다크모드 · 반응형
js/app.js                       지도 · 필터 · AI 추천 · 상세 · 해설 호출
api/chat.js                     서버리스 함수 — 근거 조립 + Gemini 호출 + 차단/오류 처리
data/places.json                거점 18곳 + 데이터셋 선언 + 검증 기록
data/exhibitions.json           전시·행사 개최 기록 1,499건 (변환 전에는 빈 배열)
scripts/geocode.js              주소 → 좌표 (카카오 로컬 API)
scripts/convert-exhibitions.js  전시·행사 CSV → JSON
tests/origin.js                 /api/chat 출처 검증 점검
tests/security.js               보안 방어 자동 점검
```

## 로컬 실행

정적 파일이라 아무 정적 서버로나 열립니다.

```bash
npx serve .          # 또는 python3 -m http.server
```

단, `/api/chat` 은 서버리스 함수라 정적 서버에서는 동작하지 않습니다.
AI 기능까지 확인하려면 Vercel CLI 를 씁니다.

```bash
npx vercel dev
```

## 배포

Vercel 에 GitHub 저장소를 연결하면 `main` 푸시마다 자동 배포됩니다.
`api/` 아래 파일이 서버리스 함수로 자동 인식되므로 별도 빌드 설정이 없습니다.
`vercel.json` 에는 빌드 설정 대신 보안 헤더만 들어 있습니다 ([SECURITY.md](SECURITY.md) 2-5 참고).

### 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | ✅ | Google AI Studio 의 **상시 무료 티어** 키. GCP 체험판 크레딧에 연결된 키는 크레딧 만료 시 서비스가 끊겨 운영 조건을 위반합니다. |
| `ALLOWED_ORIGINS` | — | `/api/chat` 을 호출할 수 있는 출처. 미설정이면 **요청이 도착한 호스트와 같은 출처만** 통과합니다(기본값이 이미 안전). 커스텀 도메인을 붙일 때만 쉼표로 나열하세요. |

카카오 JavaScript 키는 클라이언트 공개가 전제라 `index.html` 에 그대로 들어 있습니다.
보호는 **카카오 개발자 콘솔 → 내 애플리케이션 → 플랫폼 → Web** 의 도메인 등록으로 합니다.

### 모델 이름 주의

`api/chat.js` 의 `MODEL_CANDIDATES` 는 키가 속한 계정이 실제로 열어주는 모델이어야 합니다.
없는 이름으로 부르면 인증 오류가 아니라 **404** 가 돌아옵니다.
전부 404 가 뜨면 AI Studio → Playground → 모델 선택 → **Get code** 에서 정확한 슬러그를 다시 확인하세요.
표시 이름("Gemini 3.5 Flash Lite")과 API 슬러그가 다릅니다.

## 데이터 갱신

원본이 갱신되면 코드를 고치지 않고 데이터 파일만 교체합니다.

```bash
node scripts/geocode.js              # 주소 → 좌표 (KAKAO_REST_KEY 필요)
node scripts/convert-exhibitions.js <CSV경로> --facility=김대중컨벤션센터   # 전시·행사 CSV → JSON
```

데이터셋을 추가하는 것도 코드 수정이 아니라 `places.json` 의 `datasets` 선언을 늘리는 작업입니다.

## 검증

테스트 프레임워크가 없습니다. 변경 후 최소한 다음을 확인합니다.

```bash
node --check js/app.js
node --check api/chat.js
node -e "require('./data/places.json')"
```

`js/app.js` 가 참조하는 DOM id 가 `index.html` 에 모두 있는지도 함께 봅니다.
실제 화면·지도·AI 응답은 배포된 주소에서 확인해야 합니다.

보안 점검은 의존성 없이 바로 돌아갑니다.

```bash
node tests/origin.js      # 출처 검증 15건
node tests/security.js    # 인젝션·비밀 차단·헤더 등 21건
```

무엇을 막고 무엇을 못 막는지는 [SECURITY.md](SECURITY.md) 에 적어 두었습니다.
행정안전부·KISA 가 공개한 「소프트웨어 개발보안 가이드」 진단 항목에 자체 대조한 표도 함께 있습니다
(외부 기관 검토가 아니라 공개 기준에 맞춘 자체 점검입니다).

## 알려진 한계

정직하게 적어 둡니다.

- **운영시간 8/18, 입장료 7/18, 주차 4/18 곳만 확보했습니다.** 나머지는 기관 페이지가 해당 정보를 싣지 않거나 접근이 막혀 확인되지 않았습니다. 추측으로 채우지 않고 `TODO` 로 두었고, 화면에는 표시되지 않습니다.
- **전시·행사 데이터에 진행 중·예정 일정이 없습니다.** 내려받은 배포본이 2026-06-06 까지의 개최 기록이라, 앞으로 열릴 행사를 안내할 수 없습니다. 그래서 "지금 열리는 전시"가 아니라 **16년치 개최 기록의 월별 분포**로 화면을 짰습니다 — 없는 일정을 있는 것처럼 적지 않기 위해서입니다. 원본이 갱신돼 미래 일정이 들어오면 카드에 "진행 중 · 예정" 배지가 자동으로 붙습니다.
- **전시·행사 데이터의 자치구는 시설 기준으로 붙였습니다.** 원본의 `장소` 칸에는 "전시장1", "다목적홀" 처럼 시설 안의 홀 이름만 있습니다. 변환할 때 `--facility` 로 시설을 명시하면 그 시설의 자치구(김대중컨벤션센터 → 서구)를 붙입니다. 스크립트가 추측하지 않고 실행하는 사람이 지정하게 둔 이유입니다.
- **충민사의 상세 연혁을 확인하지 못했습니다.** 다수 자료가 충장사와 혼동하고 있어, 교차 확인이 될 때까지 비워 두었습니다.
- **`/api/chat` 의 출처 검증은 헤더 기반입니다.** 헤더는 위조할 수 있으므로 이 검사는 다른 사이트에 끼워 넣기와 얌체 사용까지만 막습니다. 작정하고 위조한 요청은 막지 못하며, 그때의 최종 방어선은 속도 제한과 구글 쪽 할당량입니다.
- **속도 제한은 서버리스 인스턴스마다 분리됩니다.** 인메모리 `Map` 이라 인스턴스가 늘어나면 그만큼 총량이 늘어납니다. 한 클라이언트가 한 인스턴스를 두들기는 최악의 경우를 막는 수준입니다.
